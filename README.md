# 🍽️ Bouyer Dua Restaurant

Bouyer Dua Restaurant is a modern and responsive restaurant landing page built using HTML5 and CSS3. The project showcases a fictional restaurant website with a clean layout, attractive sections, and a user-friendly design.

## ✨ Features

- Responsive design
- Modern hero section
- Navigation bar
- Restaurant introduction section
- Food menu section
- Popular dishes showcase
- Contact information section
- Attractive call-to-action section
- Clean and well-structured code

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Project Purpose

This project was created as part of my frontend development learning journey. It helped me practice semantic HTML, responsive layouts, CSS styling, and building a modern restaurant website from scratch.
